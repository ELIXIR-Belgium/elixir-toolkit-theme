## Minimal metadata

This page keeps the metadata deliberately small. It has no `description`, no contributors and no more information links, which makes it useful for checking that empty metadata sections disappear instead of leaving placeholder panels behind.

## Page image

The page still uses a `page_img`, so the example covers the image treatment in a page header and in section navigation cards without combining it with the richer metadata shown elsewhere.

### When to use this pattern

Use this pattern for short policy notes, simple explanations or pages that are mainly present so they can be linked from navigation.
