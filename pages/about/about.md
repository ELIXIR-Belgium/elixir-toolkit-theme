This project started from a practical need: a static website, deployable with GitHub Pages, that is:

- modern looking
- lightweight
- flexible enough for different branding needs
- able to handle larger documentation sets with a collapsible sidebar
- searchable

We wanted these features in an actively maintained Jekyll theme. None of the themes we tried checked all of these boxes.


At ELIXIR Belgium, we had experience using the commonly used [Jekyll Documentation Theme](https://idratherbewriting.com/documentation-theme-jekyll/) and [Just the docs](https://github.com/just-the-docs/just-the-docs). We used that experience to develop a theme that better matched the documentation, navigation and branding needs of ELIXIR-related websites.
